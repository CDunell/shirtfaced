# SHIRTFACED — CAST REFERENCE PROMPTS

**Status:** Production-history / regeneration asset. **Not canon** — `CHARACTERS.md` is narrative canon and the approved files governed by `CAST_REFERENCE_USE.md` are visual canon.  
**Purpose:** Record the prompt baseline used to create persistent cast references; use only when creating a deliberate new reference version.  
**Date:** 15 August 2026.  
**Reviewed:** 16 August 2026.

---

## Why

`CHARACTER_CONTINUITY.md` §10: *"A recurring campaign character cannot exist only as a prompt paragraph."*

The prompt is a recipe for making a candidate reference. **Once approved, the image file is the identity asset.** Later scenes should use the approved reference rather than repeatedly recreating a person from this prose.

A paired reference set uses two approved frames:

- **A — full length:** body/build/proportions and general identity.
- **B — head and shoulders:** face-critical identity.

Generate A first. Generate B with A supplied as the identity reference where the provider supports it. Do not rely on a random seed to preserve identity.

---

## Accuracy notes

This document previously contained contradictory seed instructions: it said both `two frames on the same seed` / `keep the seed` and elsewhere correctly stated that the generators in use did not expose a reusable seed. That guidance is removed.

**Current rule:** record a provider seed only if one is genuinely returned and useful for provenance. A seed is never the continuity mechanism; the approved reference file/version is.

The earlier shared preamble also specified `85mm` for full-length frames. The actual studio-reference language used for the established cast separates the two jobs more sensibly:

- **Frame A full length:** approximately 50mm normal perspective.
- **Frame B head/shoulders:** approximately 85mm portrait perspective.

Do not regenerate approved references merely to correct metadata wording in this historical prompt file.

---

## Rules for any new reference version

- Plain neutral mid-grey seamless background.
- Soft even frontal/studio light; no hard shadow.
- Full colour, sharp focus, natural skin texture, no beauty retouching.
- Frame A: full figure, head to feet, normal-perspective full-length treatment (approximately 50mm).
- Frame B: head and shoulders of **the same approved person**, approximately 85mm.
- Base wardrobe only. Scene wardrobe is stated per scene and does not become identity.
- Garments plain: no logos, graphics, text, embroidery or visible labels.
- Avoid accidental styling duplication across characters where it would make group scenes confusing.
- Do not add identity-changing features that were not owner-approved.

## Family resemblance

Gary, Emma and Grace share deep-set eyes and a heavy brow. Damo shares the family brow with his brother while remaining a distinct person. Nobody else inherits that family resemblance.

Use the approved Gary reference when deliberately creating a new family member reference version where resemblance needs reinforcement. Do not morph the family into one face.

# Shared frame prompts

## Frame A — full length

> Photographic full-length character reference on a plain neutral mid-grey seamless background. Soft even frontal studio light, no hard shadow. Normal-perspective full-figure treatment, approximately 50mm. Full figure in frame from head to feet with natural body proportions. Sharp focus, full colour, natural skin texture, no retouching. Standing naturally rather than fashion posing. Every garment completely plain — no logos, graphics, text, embroidery or visible labels. One person only.

## Frame B — head and shoulders

Generate with approved Frame A attached/reference-linked:

> Head and shoulders of this same person, preserving the exact identity from the supplied full-length reference. Three-quarter or natural slight turn as appropriate, same plain neutral mid-grey seamless background and soft even light. Approximately 85mm portrait perspective. Sharp focus, natural skin texture, no retouching. One person only.

The exact pose/expression may vary slightly by character, but identity must not.

# What the prompts do not get to decide

A generation prompt may need to describe a candidate, but it does not create canon by accident.

If a trait is absent from narrative canon and absent from the approved reference, do not promote a generator's invention into identity merely because it appeared once.

Examples:

- tattoos
- new scars
- piercings
- glasses
- jewellery
- facial-hair changes
- body-shape changes
- permanent hair changes
- ethnicity/background story implications

A deliberate owner-approved replacement reference can change visual canon; a random output cannot.

`CHARACTERS.md` records that an earlier character bible invented facts and had to be rewritten. The same discipline applies to faces and bodies.
