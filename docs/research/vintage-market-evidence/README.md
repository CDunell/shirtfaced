# Vintage Market Evidence Corpus

Evidence-backed research corpus for historical surf, skate and streetwear design mechanisms.

## Purpose

Capture **sold marketplace evidence**, not generic inspiration. Records are intended for comparative analysis of composition, typography, illustration, placement, garment architecture, colour and recurring graphic mechanisms.

This corpus is reference evidence only. Historical artwork is not a source asset for reproduction.

## Evidence rules

- A record is admitted only when the source page explicitly reports the listing as sold/ended sold.
- Marketplace, listing ID, title, sale price when exposed, era claim, brand and source URL are retained.
- Seller/listing photography remains tied to the source record. Image counts are recorded immediately; image acquisition can be performed separately where technically available and appropriate for internal research.
- Seller claims about year/authenticity are recorded as listing claims, not independently verified facts.
- Reissues/reproductions should be flagged when identifiable rather than silently mixed with originals.
- Design classification is analysis, separate from marketplace facts.

## Files

- `ebay-sold.jsonl` — normalized sold-listing records.
- `taxonomy.md` — classification vocabulary used by later visual analysis.

## Initial evidence pass

The seed corpus was built from sold eBay pages on 2026-08-13. It deliberately spans multiple visual mechanisms rather than selecting only expensive grails.
