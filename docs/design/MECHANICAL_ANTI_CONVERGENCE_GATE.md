# shirtfaced — Mechanical Anti-Convergence Gate

## Status
LOCKED. Apply before every exploratory garment render.

This converts the soft anti-convergence guidance into a mechanical pre-render gate. It constrains execution mechanics, never the idea.

## Treatment vector
For every concept assign independently:

`product + garment colour + placement + scale + medium + image geometry + density + setting + lighting + casting + era + text mode + accent colour + front/back relationship`

Concept selection happens first. If a vector fails, reroll treatment variables only. Never weaken or replace a strong idea merely to manufacture diversity.

## Recent-history window
Compare every proposed treatment against:
- the immediately previous design;
- every other design in the proposed batch;
- the previous 24 exploratory/approved designs where available.

Recent successful work creates a repetition penalty, not a precedent.

## Hard rejection rules
A proposed batch does not render if any of these fail:

1. A design shares more than 3 major treatment attributes with the immediately previous design.
2. No single setting, medium, garment colour, casting profile or environmental mood may dominate more than 40% of an exploratory batch unless the user explicitly requests it.
3. No identical `product + placement + medium` combination appears twice in one batch.
4. No identical `setting + lighting + casting energy` combination appears twice in one batch.
5. Attributes heavily used in the previous two batches receive a strong temporary selection penalty.
6. Attributes barely or never used recently receive a selection boost.
7. Repeated visual momentum is not evidence of brand fit. `The last one looked good` is never a reason to repeat its mechanics.

## Minimum spread for an 8-design exploratory batch
Unless the user requests a deliberately narrow study, an 8-design batch must contain at least:
- 3 product types;
- 2 garment colours;
- 3 media/treatment modes;
- 3 placement architectures;
- 3 environmental moods/settings where models or photography are used;
- both image-heavy and image-light work;
- 1 design with no photography;
- 1 design with no large text;
- 1 design with no acid accent;
- 1 design where the brand mark is tiny or absent.

Scale proportionally for smaller/larger batches.

## Casting distance
Casting is an execution variable and is subject to the same anti-convergence rules.

Do not allow `young + tattooed + edgy + night + hard flash` or any other repeated casting/mood cluster to become a default Shirtfaced person.

Across the rolling history vary naturally across age, gender, body, hair, personal style, tattoo presence/absence, energy, solo/pair/group and ordinary social contexts. This is not a quota and not a pivot. Any individual ingredient remains available whenever it serves the idea.

## Pre-render matrix
Before image generation, build the treatment vectors mentally or explicitly and compare them column by column.

If a column reads like:
- `night / night / night / night / night`
- `black / black / black / black`
- `photo + lime / photo + lime / photo + lime`
- `young tattooed model / young tattooed model / young tattooed model`

then the batch fails before generation.

Reroll the repeated mechanics until the batch passes.

## Fixed vs free

FIXED:
- Shirtfaced personality and judgement;
- actual Shirtfaced identity assets;
- lowercase `shirtfaced`;
- established Shirtfaced type system;
- colour discipline;
- premium streetwear credibility;
- Costume Test;
- human truth + disproportion.

FREE:
- ideas;
- subjects;
- eras;
- visual languages;
- media;
- garment/headwear form;
- placement;
- scale;
- image geometry;
- density;
- setting;
- casting;
- lighting;
- text/image relationship.

## Final gate

`shirtfaced personality = fixed`

`ideas = unrestricted`

`execution variables = randomised`

`recent repetition = penalised`

`excess similarity = automatic rejection`
