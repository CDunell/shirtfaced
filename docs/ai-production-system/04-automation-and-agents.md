# Automation and Agents

## Jobs suitable for agents

- capability research
- tool comparison
- prompt assembly
- prompt variation
- rejection logging
- metadata generation
- naming
- asset cataloguing
- derivative planning
- crop planning
- content-calendar preparation
- scheduling preparation
- analytics summaries
- test reporting
- Git updates
- issue creation
- capability monitoring
- documentation maintenance

## Jobs agents cannot safely own alone

- final visual judgment
- final product accuracy
- final typography
- licensing decisions
- commercial-usage clearance
- release approval
- deciding whether a generated clip feels real
- deciding whether content belongs in the SHIRTFACED world

## Hard limitation

Fully automated generation-to-publication is technically possible but strategically unsafe for SHIRTFACED.

Automation should handle:
- repetitive conversion
- file management
- metadata
- versioning
- scheduling preparation
- reporting

It should not silently approve creative output.
