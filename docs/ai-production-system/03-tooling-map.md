# Tooling Map

## Foundation

- ChatGPT
- Claude
- GitHub
- agents
- MCP integrations
- project knowledge documents
- prompt and rejection history

## Image generation and editing

Categories required:
- general image generator
- precision editor
- transparent-background artwork generator
- upscaler
- restoration tool
- batch resizer
- metadata writer

Candidate ecosystem to evaluate:
- OpenAI image generation
- Adobe Firefly
- Flux ecosystem
- ComfyUI
- Magnific
- Topaz
- Photoshop generative tools

## Video generation

Candidate ecosystem to evaluate:
- Veo
- Runway
- Kling
- Luma
- Adobe Firefly Video
- open-source video models

Evaluate each on:
- image-to-video quality
- identity stability
- garment stability
- camera control
- motion realism
- duration
- vertical output
- cost per usable clip
- commercial terms
- API access
- batch capability

## Editing and finishing

Candidate stack:
- DaVinci Resolve
- Adobe Premiere Pro
- After Effects
- CapCut
- Photoshop
- Topaz Video AI
- FFmpeg

The correct answer may be a stack, not one application.

## Audio

Candidate stack:
- ElevenLabs
- Adobe audio tools
- licensed commercial music libraries
- platform commercial music libraries
- AI sound-effect generators
- audio cleanup and stem tools

## Orchestration

Possible tooling:
- GitHub Actions
- local scripts
- n8n
- Make
- Zapier
- MCP servers
- custom API workflows
- scheduled agents
- cloud storage triggers

Agents should coordinate jobs. They do not replace specialist generation, editing, storage or publishing systems.

## Digital asset management

Required capabilities:
- file naming
- metadata
- searchable tags
- prompt lineage
- source-to-derivative linkage
- approval state
- collection association
- product association
- platform output tracking
- version history
- archive and retrieval

Candidate solutions must be researched before the asset library becomes large.
