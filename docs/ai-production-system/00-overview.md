# SHIRTFACED — AI Production System

## Purpose

Define what SHIRTFACED can genuinely produce with current AI systems, what cannot yet be automated reliably, what tools are required, and how generated assets can be polished into release-ready content.

This is a capability map, not a production-review checklist.

The key questions are:

- What can be generated?
- What can be transformed?
- What can be automated?
- What still breaks?
- What tooling is required beyond ChatGPT, Claude, agents, add-ons and widgets?
- How can one approved still become multiple polished release assets?

## Existing foundation

SHIRTFACED already has:
- locked brand direction
- seed documentary photography style
- product photography system
- GitHub repository as canonical memory

The product photography system should not be rebuilt here. It should only be referenced and expanded when a capability depends on it.
