# SHIRTFACED — Social Video Production Pipeline v1.0

## Purpose

Convert one approved SHIRTFACED image into one or more social-ready vertical videos with minimal manual effort and maximum consistency.

---

# Stage 1 — Master Image

Input:

- Approved 9:16 image
- Final colour grade
- No text
- No logos
- No overlays

Status:

**LOCKED**

---

# Stage 2 — Image → Video (Runway / Seedance)

Goal:

Bring the photograph to life.

NOT create a movie.

NOT invent a story.

The image already contains the story.

The model adds motion only.

### Seedance Prompt Rules

DO

- Describe motion only.
- One camera move.
- One continuous action.
- End with constraints.

DON'T

- Re-describe the image.
- Describe clothing.
- Describe lighting.
- Describe expressions already visible.
- Tell a story.

### Baseline Prompt

> Continue the existing moment naturally. The group keeps walking together at a relaxed pace. Slow handheld tracking shot following alongside. Preserve every person's identity, clothing and position. No new people. No new objects. No cuts. Consistent lighting.

Generate

- 5 seconds
- Vertical 9:16
- Highest quality

Output

MASTER_VIDEO.mp4

---

# Stage 3 — Review

Reject if:

- Face changes
- Clothing changes
- New objects appear
- Extra people appear
- Hands melt
- Walking becomes unrealistic
- Camera becomes cinematic
- Image composition changes

Approve

↓

MASTER_VIDEO_APPROVED.mp4

# Research Findings — Seedance

- Motion prompts outperform scene descriptions.
- One camera move is better than multiple.
- One continuous action is better than many.
- Short prompts (~40–80 words) outperform long cinematic prompts.
- End prompts with hard constraints (preserve identities, no new people, no new objects, consistent lighting).
- The image should carry the story; the prompt should only specify how it moves.
