# Social icons

Platform marks for the website — footer links, share buttons, an "@shirtfaced"
badge. Website chrome, not design material: nothing here goes on a garment.

Each is another party's trademark. Using a platform's own icon to link to a
profile on that platform is ordinary nominative use and is what these files are
for. Putting one on a product is a different question and a different answer.

| File | What |
|---|---|
| `instagram-icon.eps/.jpg` | Glyph mark, vector plus preview |
| `instagram-glyph.eps/.jpg` | Second glyph variant |
| `instagram-logo-variations.psd/.jpg` | Layered variations sheet |

## Attribution, which is a condition not a courtesy

`instagram-icon-license-free.txt` requires attribution to **ibrandify / Freepik**
for the free tier. `instagram-icon-license-premium.txt` covers the subscribed
tier and drops it. Both files are kept here rather than summarised, because
which one applies depends on the account the download was made from, and that is
not something this repository knows.

If the free licence applies, the attribution has to appear somewhere on the
site. That is a build task, not a filing one, and it is not done.
