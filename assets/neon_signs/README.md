# Shirtfaced neon signs

Real neon-tube renders — double-line glow, glass panel background, mounting
brackets, dust/grime texture. Box width tracks word length at a fixed font
and tube scale (verified: `bad` 865px wide vs `itsbullshitmate` 2484px wide,
height consistent ~450-465px). Transparent background (RGBA).

Delivered 2026-08-11 as `shirtfaced_actual_neon_signs_4_colourways.zip`,
replacing the first delivery (see `../neon_signs_v1_superseded/` — kept for
reference, not for use: uniform box size with font auto-scaled per word,
which doesn't match the real reference garment).

## Words

bad, beers, champion, decisions, dickhead, dramatic, fuck_off, good_times,
great_mates, itsbullshitmate, mates, nice_one, yeah_nah

## Colourways

- `amber/`, `lime/`, `white/` — neon glow colourways
- `black/` — flat printable version
