# Illustration parts

Representational artwork — an object, an animal, a place. The archive had none
of these at all before this folder existed; every design that wanted one was
falling back to a symbol.

Everything currently here is standing in. The reasons are recorded per file in
`library.json` and summarised below, so the composer can reach them while it is
obvious that none of them is finished.

## What is wrong with each

| File | Fault |
|---|---|
| `blue_heeler` | A single lump. No legs, ears, muzzle or tail. |
| `esky` | Reads as a car battery — tabs on the lid, no overhanging lip. |
| `hills_hoist` | Three bars on a pole reads as a telegraph pole. |
| `kangaroo` | An upright lump with a stray rectangle. No tail, leg or ears. |
| `kookaburra` | Two ovals and a loose parallelogram. Counter fills solid. |
| `magpie` | A lump. The pied pattern is what names a magpie, and it is absent. |
| `meat_pie` | A thick ring. Reads as a donut. |
| `snag_on_bread` | A rounded rectangle with a slot. |
| `southern_cross` | Wrong constellation — brightest star at the top, fifth star outside the kite. |
| `ute` | Reads as a hatchback. No drop behind the cab, and the wheels merge into the arches. |
| `wombat` | A lump. Counter fills solid. |
| `work_boot` | Reads as a handbag. No sole, heel or collar. |

## The pattern in the failures

Ten of the twelve are one closed outline with nothing inside it. A silhouette
carries a subject only when its edge does the naming — a kangaroo is a tail and
a hind leg, a magpie is a beak and a pied back, a ute is the vertical drop
behind the cab. Where the edge cannot carry it alone the artwork needs interior
knockouts, and those have to be wound against the outline or they fill solid,
which is what happened to the kookaburra and the wombat.
