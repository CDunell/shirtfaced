# SHIRTFACED Font System

## 1. Brand mark

Use the supplied lowercase `shirtfaced` artwork as an image/SVG mark. Do not recreate it by typing.

## 2. Primary display

Use the proprietary **Shirtfaced Regular** font for large slogans, garment headlines and campaign titles. Uppercase preferred. The approved OTF, TTF and generated WOFF2 are bundled in `primary-shirtfaced/`.

## 3. Relaxed companion

Use **SHIRTFACED Loose Regular/Medium/Italic/Wide** for secondary phrases, captions with personality and the "fuck it, why not" voice.

## 4. Utility text

Use the system/Inter stack for body copy, commerce, navigation, size charts and accessibility-critical information. This avoids another bundled font dependency.

## 5. Icons

`SHIRTFACED Icons` maps twelve approved symbols into Unicode Private Use Area codepoints. See `icons/icon-map.json`. SVG masters are included for print and design applications.

## Rules

- Maximum three roles on one layout: display, relaxed, utility.
- Never use display below 18 px or for paragraphs.
- Never use icons as text replacements when accessibility labels are required.
- Keep the original OFL and modification notice with the Loose family.
- Never substitute SHIRTFACED Loose for the proprietary Shirtfaced primary face.
