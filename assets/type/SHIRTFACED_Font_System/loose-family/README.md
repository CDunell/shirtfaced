# SHIRTFACED Loose

Anybody-based companion family for SHIRTFACED.

## Included

- Variable upright: width 50-150, weight 100-900
- Variable italic: width 50-150, weight 100-900
- Static Thin, Regular, Medium, Black, Condensed, Wide and Italic presets
- WOFF2 webfonts and CSS
- Visual proof

Install the TTF files from `fonts/`. For web use, copy `web/` and load `shirtfaced-loose.css`.
