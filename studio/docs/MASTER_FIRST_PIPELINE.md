# Master-First Image Pipeline

Status: LOCKED production guidance for World 01.

## Core decision

Do not use Nano Pro to create, reframe, extend, restage or repair the scene master.

The scene master must be finished first in the model/tool that can best create the whole event correctly — GPT image generation or another renderer selected on keeper quality.

Only after that master passes manual scene approval may it be sent to Nano Pro.

## Required order

`CANON -> WORLD/SCENE BRIEF -> MASTER GENERATION -> MANUAL SCENE APPROVAL -> NANO SURGICAL CONTINUITY EDITS -> SCENE RICHNESS RECHECK -> MANUAL STILL APPROVAL -> VEO I2V -> MANUAL VIDEO APPROVAL -> POST -> CONTINUITY ASSET`

## Scene master owns everything

The approved scene master is already the final photograph except for narrow continuity corrections.

It owns:

- aspect ratio and framing;
- camera position and lens/perspective;
- event hierarchy and attention distribution;
- crowd density and independent human behaviour;
- foreground obstruction and occlusion;
- environment and geography;
- props and physical relationships;
- lighting and exposure character;
- named-character action geometry;
- documentary mess, asymmetry and accidental composition.

If any of those are wrong, reject the master and regenerate the master upstream. Do not ask Nano to fix them.

## Nano role

Nano is a surgical editor only.

Allowed examples:

- replace one named character's face/head identity;
- correct build in a tightly bounded region;
- correct wardrobe on one character;
- correct one factual prop/detail when the rest of the master is already approved;
- use an expression-matched identity bridge for difficult head angles/expressions.

Nano must not:

- convert aspect ratio;
- extend canvas;
- outpaint the room;
- add crowd density;
- increase chaos;
- change composition;
- move people;
- reinterpret interactions;
- create new reactions;
- clean up framing;
- rebalance lighting;
- make the named character more legible by reorganising the world.

If a required change is too large to be surgical, return upstream and regenerate the scene master.

## Hard gate

Before the first Nano call, the master must already pass:

1. scene/world truth;
2. attention hierarchy;
3. crowd/event richness;
4. camera/framing;
5. action geometry;
6. aspect ratio/output format;
7. props/environment;
8. manual approval as a scene worth preserving.

Nano is never the place where we discover the composition.

## Pub 11:05 lesson

The failed 9:16 Nano experiments proved that trying to preserve a rich master while also asking Nano to reframe/extend it introduces too many degrees of freedom. It duplicated scene regions, changed crowd semantics and repeatedly turned Damo into the visual organising principle.

Therefore for `W01-P28`:

- generate the full 9:16 pub master upstream;
- get the room, chaos, camera accident, Damo action, stool/beer and attention hierarchy right in that master;
- approve that image as the scene;
- only then use Nano for tightly bounded Damo continuity corrections;
- reject any Nano edit that changes scene hierarchy or surrounding behaviour.

## Governing sentence

The scene plays out independently; we choose where to point the camera and observe it. The master captures that event. Nano may correct a character inside the photograph, but it does not get to redesign the photograph.
